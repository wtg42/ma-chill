## MODIFIED Requirements

### Requirement: 視窗高度有限時仍保留命令列

當 terminal 高度不足以完整顯示所有內容時，系統 SHALL 優先保留頂部狀態列與底部命令列；中間事件流 MUST 以可捲動視窗顯示，而不是在畫面層永久丟棄較早訊息。

#### Scenario: 高度不足時改以可捲動事件流承載內容
- **WHEN** terminal 高度不足以同時完整顯示所有事件訊息
- **THEN** 系統仍保留頂部狀態列與底部命令列，並讓中間事件流可捲動回看較早內容

### Requirement: 中間區域為可回溯事件流

系統 SHALL 以時間順序顯示遊戲事件流，內容包含摸牌、棄牌、吃碰槓胡、勝負結果、系統提示與命令執行回饋。最新內容 SHALL 出現在事件流尾端，使用者 MUST 可回看較早訊息；當事件流目前位於底部時，新內容追加後視窗 SHALL 自動跟隨最新內容；當使用者已手動捲離底部時，新內容追加 MUST NOT 強制將視窗拉回尾端。

#### Scenario: 位於底部時新事件自動跟隨
- **WHEN** 事件流目前位於最新內容尾端，且系統再追加一筆新事件
- **THEN** 視窗自動跟隨到最新內容，讓玩家直接看到新事件

#### Scenario: 回看歷史時新事件不打斷閱讀
- **WHEN** 使用者已手動將事件流捲到較早位置，且系統再追加一筆新事件
- **THEN** 新事件仍被追加到事件流尾端，但目前視窗保持在原本回看位置，不強制跳回最新內容
